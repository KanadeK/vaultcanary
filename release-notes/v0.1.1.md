# VaultCanary v0.1.1

Test a password-manager migration using 17 disposable synthetic probes, then identify
preserved, relocated, or missing fields from Bitwarden JSON/CSV and 1Password 1PUX.

This is the first downloadable release. It updates the development toolchain's
transitive urllib3 dependency to the patched 2.8.0 release. Runtime dependencies remain
zero, and no audit behavior changed. The existing v0.1.0 tag has not been moved.

## Assets

- Python wheel and source distribution.
- Example ZIP with a passing JSON export and two deliberately lossy return exports.
- SHA256SUMS.txt for the downloadable assets.

## Acceptance

```console
python -m pip install vaultcanary-0.1.1-py3-none-any.whl
vaultcanary audit examples/vaultcanary-manifest.json examples/known-good-bitwarden.json
```

The known-good example must report `PASS: 17/17 features preserved` and exit `0`.
The lossy CSV and 1PUX examples must report `REVIEW` and exit `1`. Malformed inputs
exit `2` without copying input values into the report.

## Limits

No online account access, encrypted exports, KDBX, attachments, or passkey transfer.
A pass proves the synthetic feature contract for the tested import/export path only.
