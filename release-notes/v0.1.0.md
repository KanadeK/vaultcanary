# VaultCanary v0.1.0

Test a password-manager migration with disposable fake records before trusting it with
real credentials.

## Included

- Bitwarden JSON canary generation with 17 feature probes.
- Return-export audits for Bitwarden JSON/CSV and 1Password 1PUX.
- `preserved`, `relocated`, and `missing` evidence without reporting vault values.
- Terminal, stable JSON, and script-free standalone HTML outputs.
- Zero runtime dependencies, offline operation, and explicit exit codes.
- Wheel, source distribution, generated example bundle, and checksums.

## Acceptance

```console
vaultcanary audit examples/vaultcanary-manifest.json examples/known-good-bitwarden.json
```

The command must report `PASS: 17/17 features preserved` and exit `0`. The two lossy
examples in the bundle must report `REVIEW` and exit `1`.

## Limits

This release does not handle encrypted exports, KDBX, attachments, passkeys, browser
profiles, or online accounts. A pass proves only the tested synthetic v0.1.0 contract.
